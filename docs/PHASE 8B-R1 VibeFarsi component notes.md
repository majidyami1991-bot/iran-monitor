# Phase 8B-R1: VibeFarsi component notes

This phase used selected interaction patterns from VibeFarsi's documented components: Card, Badge, Stat, Tabs, Search Input, Empty State, Alert, Accordion, and Data Table. The local, small RTL implementations are in `apps/web-next/app/vibefarsi.tsx`; they use the project's existing React, CSS, and Tailwind 3.4 setup. They were hand-written/adapted; no component package, VibeFarsi CLI, Tailwind upgrade, dependency, theme replacement, or bulk source copy was used. Components are intentionally limited to pages touched by this phase.

The VibeFarsi site describes the project as free/open source, its documentation describes copy-as-source usage and currently targets Tailwind CSS 4, and its official GitHub repository identifies the project as MIT licensed. Reference pages reviewed: [VibeFarsi home](https://vibefarsi.ir/), [documentation](https://vibefarsi.ir/docs), [Card](https://vibefarsi.ir/components/card), [Badge](https://vibefarsi.ir/components/badge), [Stat](https://vibefarsi.ir/components/stat), [Tabs](https://vibefarsi.ir/components/tabs), [Search Input](https://vibefarsi.ir/components/search-input), [Empty State](https://vibefarsi.ir/components/empty-state), [Alert](https://vibefarsi.ir/components/alert), [Accordion](https://vibefarsi.ir/components/accordion), [Data Table](https://vibefarsi.ir/components/data-table), and [official repository license](https://github.com/TronIsHere/vibafarsiui).

No VibeFarsi source file was copied verbatim, so no upstream copyright notice was removed. This note records the design/reference attribution and the MIT license identified by the upstream repository.
